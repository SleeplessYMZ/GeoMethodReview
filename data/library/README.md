# Monthly Library

本目录保存从目标 GIScience 期刊中自动筛选出的月度方法文献候选集。

## 筛选规则

文章标题和 Crossref 摘要中只要命中 `方法家族` 关键词，即进入候选库。脚本同时记录以下辅助标签：

1. 方法家族：GeoAI、机器学习、神经网络、图模型、空间统计、时序/时空建模、因果推断、仿真优化、遥感视觉、空间交互等。
2. 数据来源：遥感影像、街景、轨迹、传感器、OSM、基础地理数据库等。
3. 时空分析语境：空间尺度、空间依赖、时间动态、城市区域、环境监测和灾害风险等。

如果 Crossref 没有提供摘要，则仅根据标题判断。CSV 中的 `abstract_available` 字段会标明摘要是否可用于筛选。

月度 CSV 仅保存文章元数据、DOI、命中的主题和关键词，不保存完整摘要。自动筛选结果仍需人工复核，尤其要判断文章是否真正具有方法贡献。

## 更新方式

默认抓取从 2026 年 1 月至上一个完整月份的数据：

```bash
node scripts/fetch-crossref.mjs
```

也可以指定月份范围：

```bash
node scripts/fetch-crossref.mjs --from 2026-01 --to 2026-05
```
